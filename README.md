# Analytics Studio

A responsive financial analytics dashboard built as part of the UI/UX Engineering Bootcamp – Task 05.

## Design & Flowchart
[View Analytics Studio Flowchart – Whimsical](https://whimsical.com/sportsnextindia/analytics-studio-3XEeusVWgK1Ha4V1hAb9hG)

## Features

- Financial overview with KPI cards and charts.
- Transaction search and status filters.
- Add new transactions.
- LocalStorage data persistence.
- Five UI states: Ideal, Empty, Loading, Error and Overflow.
- Responsive layout and keyboard accessibility.

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Browser LocalStorage

## Run Locally

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Run `index.html` using Live Server.
